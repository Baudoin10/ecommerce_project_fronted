# E-Commerce Based Web Application

Final-year project for the **Bachelor of Science with Honours in Software Engineering** at the **University of Lay Adventists of Kigali (UNILAK)**, Rwanda.

## Overview

An e-commerce web application that lets customers browse and buy products online and have them delivered to their homes, so they don't need to visit a physical market.

## Features

- Product catalogue with categories and search
- Shopping cart and checkout
- Order placement and order management
- User registration and authentication
- Admin management of products and orders

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React.js, Redux |
| Backend | Node.js |
| Database | MongoDB |

## Getting Started

### Prerequisites

- Node.js and Yarn installed
- The backend API running (see the backend repository)

### Install and run

```bash
yarn install
yarn start
```

The app runs at [http://localhost:3000](http://localhost:3000).

### Build for production

```bash
yarn build
```

The optimised build is created in the `build` folder.
